# Medical Triage AI | Documentation expérimentale

Site HTML statique. Ouvrir `index.html` dans un navigateur, ou lancer un serveur statique.

## Arborescence
- `index.html` : consigne, présentation et fil conducteur.
- `data.html` : qualité, audits et gouvernance des données.
- `experiments.html` : six runs SFT, baseline et visualisations.
- `dpo.html` : runs DPO, analyse appariée et visualisations.
- `architecture.html` : architecture technique et MLOps.
- `css/style.css` : style partagé.
- `js/main.js` : interactions.
- `assets/` : graphiques SVG et données structurées.

## Provenance et limites
Les valeurs affichées sont reprises des pages HTML fournies. Les six runs SFT historiques ne sont pas nécessairement comparables à la baseline finale si les jeux d'évaluation diffèrent. Les courbes d'entraînement détaillées, les durées et les métriques DPO 02 ne sont pas inventées. Les éléments encore à vérifier sont explicitement indiqués.

Les graphiques sont des SVG statiques accessibles, sans CDN ni dépendances JavaScript externes.
