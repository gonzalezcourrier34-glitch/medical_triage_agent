AI ENGINEERING • MLOPS

Du modèle au système.

Le modèle entraîné n'est qu'un composant du projet. L'objectif est de construire une chaîne reproductible allant des données jusqu'à l'exposition du modèle sous forme de service d'inférence.

Data Engineering Qwen3 QLoRA FastAPI vLLM Docker GitHub Actions Monitoring
Voir le pipeline Déploiement

01

Une architecture de bout en bout

Data Engineering + Machine Learning + LLM Fine-Tuning + Evaluation + MLOps + Software Engineering.

Le POC ne se limite pas à entraîner un adapter LoRA dans un notebook.

Les données doivent être préparées et contrôlées, les expériences tracées, le modèle évalué, les artefacts versionnés puis le résultat exposé à travers une interface exploitable.

Cette séparation permet également de faire évoluer indépendamment les différentes briques du système.

04

Architecture d'entraînement

La stratégie QLoRA permet de spécialiser le modèle sous la contrainte des 6 Go de VRAM disponibles.

BASE MODEL Qwen3-1.7B Poids principaux gelés • quantification 4 bits
+
ADAPTERS LoRA r=16 • alpha=32 • dropout=0,05
+
OPTIMISATION MÉMOIRE QLoRA Gradient checkpointing • AdamW 8-bit
GPU RTX 4050
VRAM 6 Go
Quantification 4 bits
Batch GPU 1

Configuration

Les paramètres dépendant de l'environnement restent séparés du code applicatif.

.env Exemple

MODEL_VERSION=...
VLLM_URL=...
MAX_MODEL_LEN=...

SÉCURITÉ Les secrets ne sont pas versionnés dans Git.

Tokens, mots de passe, clés API et identifiants cloud doivent être gérés séparément du code source.

Monitoring et traçabilité

Mesurer le temps nécessaire pour traiter une requête et générer une réponse.

Traçabilité

Associer une réponse à une version du modèle et à une configuration identifiables.

13

Un POC, pas un dispositif médical

Risques modèle

  • Sous-triage
  • Hallucinations
  • Biais linguistiques
  • Erreurs de généralisation

Risques système

  • Indisponibilité du service
  • Erreur d'intégration
  • Traçabilité insuffisante
  • Mauvaise version du modèle

Enjeu médical

Une performance expérimentale ne constitue pas une validation clinique.

Supervision humaine

Le système est étudié comme outil d'assistance. La décision médicale reste sous responsabilité humaine.
